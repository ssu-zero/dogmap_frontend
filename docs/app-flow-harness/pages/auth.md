# 인증과 약관

`/login → /onboarding/1 → /onboarding/2 → /terms → /`

약관은 전체 동의와 필수 동의를 지원한다. 제목·안내 영역은 상단에 유지하고,
`모두 동의하기 → 필수 약관 3종 → 확인`은 한 개의 하단 액션 영역으로 화면 하단에
고정한다. 따라서 충분한 화면 높이에서는 CTA와 동의 항목이 함께 하단에 붙고, 짧은
화면에서는 해당 블록이 잘리지 않도록 페이지 전체가 자연스럽게 세로 스크롤된다. 완료
전에는 `확인`을 비활성화한다. `/terms/[slug]`는 온보딩·마이페이지에서 공통으로
진입하며 뒤로가기로 이전 문맥을 유지한다.
