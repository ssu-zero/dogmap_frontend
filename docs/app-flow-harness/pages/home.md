# 홈

`/`은 로그인과 반려견 등록을 완료한 사용자의 첫 화면이다. 화면은 상단 히어로와
주변 동반 가능시설 목록, 4개 탭 하단 내비게이션으로 구성한다.

## UI 계약

- Figma 상태바나 브라우저 하단 UI를 별도 요소로 만들지 않는다. 홈의 모든 Figma 세로
  좌표는 상태바 `62px`를 뺀 값으로 구현한다. 즉 히어로와 흰 시설 패널의 시작점도 함께
  위로 이동하며, 상단에 어두운 Safe Area 여백을 남기지 않는다.
- 히어로에는 Figma 원본의 물결 배경, 로고, 반려견 이미지, `오늘 {반려견 이름}랑`
  제목과 `코스 만들기` CTA를 사용한다. 이름만 브랜드 red-600으로 강조한다. 반려견
  이미지는 원본 크기(`206×260`)와 오른쪽 배치(`left: 187px`)를 유지한다. 흰 시설
  패널이 강아지 하반신 위로 올라와 하단을 가리는 것이 의도된 레이어 순서다. 이 겹침은
  상단 Safe Area를 제외한 뒤에도 같은 비율을 유지한다.
- 시설 영역은 `gray-200` 2px 상단 경계로 히어로와 구분하며, 제목·동작구 위치 표시·안내문·
  카테고리 칩 순으로 배치한다.
- 선택된 카테고리는 `gray-900` 배경과 `gray-50` 텍스트, 나머지는 `gray-50` 배경과
  `gray-200` 텍스트를 사용한다. 실제 API 요청은 선택된 카테고리를 유지한다.
- 장소 카드는 이름, 반려견 동반 범위, 카테고리·거리, 발자국 수, 썸네일을 한 카드 안에
  보여준다. live API에서는 장소 데이터를 사용하고, demo mode에서는 Figma 기준 fixture를
  사용한다.
- 하단 내비게이션은 홈·코스·커뮤니티·마이페이지 4개이며, 현재 탭만 12px semibold·
  `gray-900`으로 표시한다. 코스 아이콘은 위치 핀이 아니라 발바닥 아이콘을 사용한다.
